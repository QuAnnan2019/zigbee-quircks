# Zigbee Quirk 与 Converter

[English](README.md)

本仓库用于集中维护 Zigbee 设备面向以下平台的本地接入代码：

- Home Assistant ZHA 自定义 Quirk
- Zigbee2MQTT 外部 Converter

每项接入按平台、厂商和设备型号组织。仓库只保存经过整理的接入源码，
不作为原始协议资料、实验文件、部署示例或开发进度的汇集位置。

## 规划目录

```text
zha/<厂商>/<型号>/
z2m/<厂商>/<型号>/
```

设备目录只存放对应平台的实现代码。

## 范围

本仓库只保存接入源码。本地协议清单、抓包、日志、部署示例、开发中实验文件和
个人开发进度记录保留在仓库外的本地工作区。
